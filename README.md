# 赛鸽血统环号登记站

运行：

```bash
npm start
```

访问`http://localhost:3024`。支持档案、血统查询、转让、归巢成绩记录，以及档案纠错（足环换号）。

## 档案纠错（换号）

原环录错时不再新开档案，在页面“档案纠错申请”提交**原环、新环、纠错原因、来源说明**：

- 申请提交后为“待核”状态，**核对通过后才换号**；可驳回（驳回不动任何档案）。
- 新环已被别的鸽只占用（含其它待核申请预留、已退役旧环）时拒绝提交；核准时再复核一次，被占用则中止，两边档案不改。
- 核准后：本鸽改挂新环，**旧环保留在环号变更记录**；父母及子代引用一并改指新环；疫苗、转让、成绩原样保留。
- 按**原环或新环**都能查到同一份血统（用旧环查询会提示为旧环）。

接口：`POST /api/corrections`（提交）、`GET /api/corrections`（申请列表）、`POST /api/corrections/:id/review`（核对，body：`{"approved":true/false,"note":"..."}`）。

## 文件结构

按职责拆成三个业务文件：

- `server.js` — 入口层：HTTP 路由与页面。
- `correction.js` — 纠错判定层：提交校验、占用拒绝、核对换号规则。
- `store.js` — 存储层：棚册 JSON 读写，及当前环 / 历史旧环查询。
